REX NIRAJ PREMIUM WEBSITE

Deploy instructions:
1. Extract this ZIP.
2. Upload the CONTENTS of this folder to your existing Netlify site (not the ZIP itself).
3. Ensure index.html, robots.txt, sitemap.xml and assets/ are at the deploy root.
4. Keep the same site URL: https://verdant-bavarois-669c8f.netlify.app/
5. In Google Search Console, submit sitemap.xml and inspect the homepage after deployment.

The existing Google verification meta tag is retained. Photos are in assets/. The language toggle switches the bilingual content between English and Hindi.
