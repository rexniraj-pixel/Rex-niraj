REX NIRAJ — GITHUB PAGES PACKAGE

This is a static HTML website and is compatible with GitHub Pages.

PUBLISHING STEPS (mobile or desktop):
1. Sign in at https://github.com/ and create a NEW repository.
2. Recommended repository name: YOUR-GITHUB-USERNAME.github.io
   (Replace YOUR-GITHUB-USERNAME with your actual GitHub username.)
3. Set repository visibility to Public and create the repository.
4. Choose Add file > Upload files.
5. Extract this ZIP first, then upload ALL CONTENTS of the extracted folder.
   Important: index.html, .nojekyll, robots.txt, sitemap.xml, README.txt,
   README-GITHUB.txt and assets/ must be at the repository root.
6. Commit the upload.
7. Open repository Settings > Pages. Under Build and deployment, choose
   Deploy from a branch, select main and /(root), then Save.
8. Wait for GitHub Pages to publish. The address will be:
   https://YOUR-GITHUB-USERNAME.github.io/
